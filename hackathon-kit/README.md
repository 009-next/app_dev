# Connect-Force ハッカソン提出キット

Connect-Forceの発表、技術記事、来場者向け案内をまとめた公開用キットです。現場の記録を根拠付きで整理し、対応案の比較から人の承認までを一つのMission Roomで体験できます。

## 収録物

- `Connect-Force_ハッカソン発表資料_20260921_E2E_最終版_v3.pptx`: 発表用スライド
- `Connect-Force_来場者パンフレット.pdf`: 展示ブース配布用パンフレット
- `qiita-connect-force.md`: Qiita記事下書き
- `zenn-connect-force.md`: Zenn記事下書き
- `assets/`: スライド・記事・パンフレットで使う画像

## 発表で伝える内容

- セキュリティ: 入力検査、承認、CSRF、限定した音声送信経路をコードで制御
- コストパフォーマンス: PC版の通常分析はモデル呼出し0回。音声分析は回数と予算を制限
- 信頼性: 43件の自動・HTTP統合テストとORCA ROUTER実環境E2Eを実施
- 自律性: 目的、危険度、根拠、予算に合わせて処理を選択し、候補を下書き化
- 独創性: 過去、現在、未来、行動を一つの作業室に集約

## 実環境E2E

2026年9月21日に、27.684秒の音声をORCA ROUTERへ3回連続で送信し、すべてHTTP 200で完了しました。各回は766入力token・60出力tokenで、公開単価に基づく合計見積は$0.0011394です。デモの上限は$2です。

公開物には実データ、APIキー、環境変数の値を含めません。
