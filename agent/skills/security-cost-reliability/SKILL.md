# 安全・原価・信頼性の評価

評価では、文章上の方針とコードで強制される境界を分ける。

1. 取得するデータ、保存場所、保存期間、外部送信先を確認する。
2. マスキング、認証、権限、承認、入力検証がコードで強制されるか確認する。
3. AI呼び出し回数、入力・出力・キャッシュのトークン、1成果物あたりの金額を確認する。
4. AI出力に根拠IDがあり、存在確認できるか確認する。
5. 黒画像、無音、低信頼度、通信断、予算超過、権限拒否時の代替経路を確認する。

評価結果は「満たす」「一部」「未実装」に分け、未実装を満たす証拠を示す。
